# L04 세션을 여러 개 돌릴 땐 클립보드를 쓰지 않는다

- **날짜**: 2026-09-24
- **무슨 일이 있었나**: 긴 프롬프트를 클립보드에 복사해 붙여 넣는 사이, 같은 컴퓨터의 다른 AI 세션이 클립보드를 덮어썼다. 다른 세션의 파일 경로 문자열이 그대로 영상 생성 프롬프트로 제출됐다.
- **손실**: 8초 클립 1개 · 12크레딧
- **규칙**: 여러 세션이 돌 때는 클립보드 대신 파일로 주고받거나 직접 입력한다. 붙여 넣었다면 제출 전에 앞머리를 눈으로 확인한다.
- **Why**: 클립보드는 컴퓨터 전체가 하나를 같이 쓴다. 세션끼리는 서로가 언제 복사하는지 모른다.
- **How to apply**: 세션 2개 이상 동시 실행 때. 혼자 쓰면 `harness.json`의 `bash_rules_off`에 `G7`을 넣는다.
- **강제 장치**: G7 — `guard_bash.py`가 `pbcopy` · `xclip` 등을 막는다.
