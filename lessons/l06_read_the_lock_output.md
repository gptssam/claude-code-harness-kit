# L06 잠금을 "받았다"고 믿기 전에 출력 줄을 읽는다

- **날짜**: 2026-10-07
- **무슨 일이 있었나**: 잠금을 기다리다 시간 초과로 끝났는데, 명령이 파이프 뒤에서 종료 코드 0처럼 보여 잠금을 받은 것으로 잘못 읽었다. 다른 세션이 쥐고 있는 동안 제출해 버렸다.
- **손실**: 경고 · 손실은 없었지만 L05 규칙이 사실상 무너진 순간
- **규칙**: 제출 직전 출력에 `LOCKED <이름>: <내 세션>` 줄이 있는지 확인한다. 없으면 제출하지 않는다.
- **Why**: 종료 코드는 파이프 · 백그라운드 실행에서 쉽게 가려진다. 글자는 가려지지 않는다.
- **How to apply**: `lock.py acquire ... | tail` 처럼 감싸 쓸 때 특히.
- **강제 장치**: `lock.py`가 시간 초과 때 `TIMEOUT … you do NOT hold the lock`을 찍는다.
