# L07 커밋은 내가 바꾼 경로만

- **날짜**: 2026-10-04
- **무슨 일이 있었나**: 한 줄 고친 뒤 `git commit -am`으로 커밋했더니, 같은 폴더에서 일하던 다른 세션들이 아직 커밋하지 않은 변경 10개가 같이 커밋 · 푸시됐다.
- **손실**: 내용 손실은 없지만 이력이 섞였고, 되돌리려면 강제 푸시가 필요해 그대로 둠
- **규칙**: `git status --short`로 내 파일만 골라 `git add <경로>` 뒤 커밋한다. `-a` · `-A` · `.` 금지.
- **Why**: 한 작업 폴더를 여러 세션이 같이 쓰면 "지금 바뀐 것 전부"는 내 것이 아니다.
- **How to apply**: 모든 커밋. 실수했으면 강제 푸시로 덮지 말고 사람에게 바로 알린다.
- **강제 장치**: G2(`commit -a`) · G3(`add -A`/`add .`) · G4(`push --force`) — `guard_bash.py`.
