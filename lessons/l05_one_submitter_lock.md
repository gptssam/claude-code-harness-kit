# L05 같은 계정 · 같은 자원은 한 번에 한 세션만 쓴다

- **날짜**: 2026-10-02
- **무슨 일이 있었나**: 두 세션이 같은 AI 영상 생성 계정에 거의 같은 시각에 작업을 보냈다. 서비스가 "비정상적인 활동"으로 막았다. 각 세션은 자기 화면만 봐서 상대의 제출을 알 수 없었다.
- **손실**: 생성 0 · 차감 0(운이 좋았음). 반복되면 계정 제한 위험
- **규칙**: 공용 자원(계정 · 렌더 자리 · GPU)을 쓰기 직전 `lock.py acquire`, 끝나면 `release`.
- **Why**: "한 번에 하나만"이라는 말은 각 세션이 서로를 볼 수 있을 때만 지켜진다. 잠금 파일은 모두가 보는 한 곳이다.
- **How to apply**: 제출 · 업로드 · 무거운 렌더 직전. 30분 넘게 묵은 잠금은 지우지 말고 사람에게 묻는다.
- **강제 장치**: `scripts/lock.py`(원자적 `mkdir` 잠금 + `lock_log.csv` 기록).
