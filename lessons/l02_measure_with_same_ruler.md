# L02 "통과"는 기준을 먼저 적고 같은 잣대로 잰 뒤에 말한다

- **날짜**: 2026-09-30
- **무슨 일이 있었나**: 레퍼런스 영상을 재현한 시험 클립 6개를 "전부 통과"로 보고했다. 사람이 영상을 보고 5가지(움직임 속도 · 글자 크기 · 원근 등)를 짚었고, 다시 재 보니 5건 모두 사실이었다. 정지 화면 내용만 비교하고 움직임은 재지 않았다.
- **손실**: 시험 클립 재제작 한 바퀴
- **규칙**: 통과 판정 전에 "무엇을 어떤 단위로 잴지"를 먼저 적고, 원본과 결과를 같은 잣대로 잰 표를 같이 낸다.
- **Why**: 기준 없이 "비슷하다"고 하면 AI는 보기 쉬운 것만 보고 통과시킨다.
- **How to apply**: 비교 · 재현 · 품질 판정 작업 전부. 측정 정의는 `specs/`에 사람이 적는다.
- **강제 장치**: `specs/`(읽기 전용, W1) + `checks/check_*.py` — 채점 기준은 사람이, 채점은 스크립트가.
