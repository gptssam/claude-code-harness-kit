# L01 "완료"라고 말하기 전에 숫자로 확인한다

- **날짜**: 2026-09-17
- **무슨 일이 있었나**: 영상에 효과음을 넣었다고 보고했지만, 소리 크기를 재지 않고 넣어 목소리보다 약 10dB 작았다. 미리듣기 파일도 엉뚱한 시각으로 잘라 "효과음이 안 들린다"는 지적을 받았다.
- **손실**: 수정 · 재검토 한 번. 무엇보다 "완료"라는 말을 믿을 수 없게 됨
- **규칙**: 결과를 "됐다"고 말하기 전에 검사를 돌리고, 검사 숫자를 보고에 그대로 적는다.
- **Why**: AI는 작업을 마친 것과 결과가 맞는 것을 구분하지 못한 채 완료를 보고한다. 사람이 직접 열어 보기 전까지 아무도 모른다.
- **How to apply**: 파일을 바꾼 모든 작업. 보고에는 `RESULT n/n PASS` 줄을 붙인다.
- **강제 장치**: V1 — `verify_gate.py`(Stop 훅)가 파일을 바꾼 턴의 끝마다 `scripts/verify.py`를 돌리고, 실패하면 끝내지 못하게 돌려보낸다.
