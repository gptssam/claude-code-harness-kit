# L08 서브에이전트에게는 "어디를 읽기만 할지"를 적어서 맡긴다

- **날짜**: 2026-10-05
- **무슨 일이 있었나**: 검색을 맡긴 서브에이전트가 만든 변환 스크립트가 원본 옆에 결과를 다시 쓰는 구조여서, 다른 작업 폴더의 텍스트 파일 808개를 덮어썼다. 110개는 git으로 되돌리고 61개는 다시 만들었지만 8개는 복구하지 못했다.
- **손실**: 파일 8개 영구 손실 · 복구 작업 반나절
- **규칙**: 서브에이전트 지시에 "이 폴더 밖은 메모리에서만 읽고, 디스크에 어떤 파일도 만들거나 고치지 말 것 · 결과는 <내 폴더>/ 아래에만"을 명시한다.
- **Why**: "이 폴더 밖은 쓰지 마"만으로는 부족하다. 도구가 만든 스크립트가 원본 옆에 쓰는 것까지 막아야 한다.
- **How to apply**: 서브에이전트 · 병렬 세션에 검색 · 변환을 맡길 때마다.
- **강제 장치**: W1 — `guard_write.py`가 `protected_paths`(raw/ · specs/ · _archive/ · .env) 쓰기를 막는다. 단, 훅은 Write/Edit 도구만 본다 — 스크립트가 직접 쓰는 것까지는 못 막으므로 지시문이 같이 필요하다.
