# L03 지우지 말고 옮긴다, 덮어쓰지 말고 새로 쓴다

- **날짜**: 2026-09-26
- **무슨 일이 있었나**: 자동 실행 중 오래된 결과물을 `rm -r`로 지우고 `ffmpeg -y`로 같은 이름에 덮어쓰는 명령을 썼다. 되돌릴 수 없는 명령이라 멈췄고, 이후 "지우기 → 보관 폴더로 옮기기", "`-y` → `-n`"으로 바꾸자 작업이 막힘 없이 진행됐다.
- **손실**: 없음(실행 전에 멈춤). 실행됐다면 원본 영상 복구 불가
- **규칙**: 바꿔야 할 파일은 `_archive/<날짜>_<이름>`으로 옮긴 뒤 새로 쓴다. 정말 지워야 하면 사람에게 명령을 건네 직접 지우게 한다.
- **Why**: AI가 지운 파일은 휴지통에도 없다. 덮어쓴 파일은 원래 무엇이었는지조차 모른다.
- **How to apply**: 정리 · 다시 만들기 · 변환 작업 전부.
- **강제 장치**: G1(`rm -r`), G6(`ffmpeg -y`), G5(`git reset --hard` 등) — `guard_bash.py`.
