# 데모 채점 기준 — 쇼츠 제목 10개 (`titles_spec.json`을 사람이 읽기 쉽게 옮긴 것)

주제: **「밤에 아파트 엘리베이터가 층마다 서는 이유」** 쇼츠 제목 후보를 `demo/titles.csv`에 씁니다.

| 항목 | 규격 |
|---|---|
| 머리줄 | `no,title` |
| 줄 수 | 정확히 10줄, 1~10번 |
| 길이 | 제목마다 12~24자 (띄어쓰기 포함) |
| 숫자 | 제목마다 숫자 1개 이상 |
| 금지어 | 무조건 · 100% · 보장 · 대박 · 충격 · 역대급 · 필수 |
| 중복 | 없음 |

채점은 `checks/check_titles.py`가 합니다. `specs/`는 에이전트가 고칠 수 없습니다(W1) — 채점 기준은 사람만 바꿉니다.
